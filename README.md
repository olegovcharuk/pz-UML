# Практична робота: Побудова поведінкових UML-діаграм
**Тема:** Проєктування системи автоматизації інформаційно-аналітичної діяльності (Information & Analysis System)

## Опис проєкту
Система призначена для автоматизації циклу аналітичної роботи: від моніторингу первинних джерел інформації до генерації фінальних аналітичних записок для керівництва. Вона дозволяє систематизувати великі масиви даних, виявляти тренди та забезпечувати верифікацію інформації.

**Основні етапи роботи системи:**
1.  Агрегація даних з відкритих джерел (OSINT), баз даних та ЗМІ.
2.  Інтелектуальний аналіз та класифікація контенту.
3.  Формування звітів та візуалізація аналітики.

---

## 1. Діаграма варіантів використання (Use Case Diagram)
Відображає взаємодію Аналітика, Системи та Керівника (Decision Maker) із функціоналом платформи.
```mermaid
flowchart LR
    Analyst(["Аналітик"])
    System(["Автоматизована система"])
    Manager(["Керівник (Замовник)"])

    subgraph "Платформа аналітики"
        UC1("Моніторинг джерел")
        UC2("Верифікація інформації")
        UC3("Аналіз трендів та ризиків")
        UC4("Генерація звітів")
        UC5("Затвердження стратегічних рішень")
    end

    Analyst --> UC1
    Analyst --> UC2
    Analyst --> UC3
    Analyst --> UC4
    System --> UC1
    System --> UC3
    UC4 --> Manager
    Manager --> UC5
```

## 2. Діаграма послідовності (Sequence Diagram)
Описує процес створення термінової аналітичної довідки за запитом.
```mermaid
sequenceDiagram
    autonumber
    participant Man as Керівник
    participant Ana as Аналітик
    participant Sys as Аналітична Система
    participant DB as Бази даних / OSINT

    Man->>Ana: Запит на аналіз ринку/події
    Ana->>Sys: Створення завдання на моніторинг
    Sys->>DB: Збір релевантних даних
    DB-->>Sys: Масив сирих даних
    Sys->>Sys: Автоматична класифікація (NLP/AI)
    Sys-->>Ana: Попередні результати (Тренди)
    Ana->>Ana: Перевірка та інтерпретація даних
    Ana->>Sys: Формування фінального звіту
    Sys-->>Man: Доставка аналітичної записки
```

## 3. Діаграма діяльності (Activity Diagram)
Візуалізує логіку обробки інформації: від отримання даних до прийняття рішення про їхню публікацію у звіті.
```mermaid
stateDiagram-v2
    [*] --> DataCollection: Збір інформації
    DataCollection --> DataProcessing: Первинна обробка
    
    state "Чи достатньо даних?" as check_data <<choice>>
    DataProcessing --> check_data
    
    check_data --> DataCollection : Ні (Додатковий пошук)
    check_data --> Verification : Так (Дані зібрано)
    
    state Verification {
        [*] --> SourceAnalysis: Перевірка надійності джерел
        SourceAnalysis --> FactChecking: Зіставлення фактів
    }
    
    state "Чи підтверджена інформація?" as check_valid <<choice>>
    Verification --> check_valid
    
    check_valid --> Archive : Фейк / Маніпуляція
    check_valid --> ReportGeneration : Валідно
    
    ReportGeneration --> Visualization: Візуалізація (Графіки/Дашборди)
    Visualization --> [*]: Звіт готовий до розсилки
```
